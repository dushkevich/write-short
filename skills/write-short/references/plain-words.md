# Plain-word swaps

Use these lists while editing (rule 17). They are examples, not a full list. The test is always the same: does the word carry meaning the reader can use?

## Filler: delete

basically · actually · essentially · in fact · of course · obviously · clearly · needless to say · it's worth noting that · it's important to note that · as you know · honestly · to be honest · frankly · I think / I believe / it seems to me (unless you contrast your view with someone else's) · in my opinion · by the way · incidentally · side note · in order to (→ "to") · at the moment / currently / as of now (the present tense already says it) · in today's world · going forward · I hope this helps · let me know if you have any questions · great question

## Praise and boosters: swap for a fact

| Instead of | Write |
|---|---|
| works great / works perfectly | what you ran and what you saw: "ran it 3 times, all 3 posted" |
| successfully deployed | "the new version is live; I opened the page and it loads" |
| robust / reliable / solid | how often it fails, or what it survives: "kept working when the internet dropped for 5 minutes" |
| significant / huge / massive improvement | before vs. after: "was 9 s, now 3 s" |
| critical / crucial / key | why it matters: "without it, nothing posts" |
| clean / elegant | usually nothing; delete |
| very / really / extremely / truly / highly | delete, or give the number |

## Fancy → plain

| Fancy | Plain |
|---|---|
| utilize | use |
| facilitate | help |
| commence / initiate | start |
| terminate | end, stop |
| leverage | use |
| implement | build, add, do |
| ascertain | find out |
| prior to | before |
| subsequent to | after |
| in the event that | if |
| due to the fact that | because |
| with regard to | about |
| a number of | the number: "4" |
| perform / conduct / carry out a check | check |
| make a decision | decide |
| provide assistance | help |

## Vague → exact

| Vague | Ask, then write the answer |
|---|---|
| some / several / a few / various | how many? which ones? |
| soon / shortly / in a while | when? "by 15:00", "in about 10 minutes" |
| recently | when? "since Monday" |
| a lot / many / lots | how many? |
| about / around / roughly | keep it only if you really don't know the exact number |
| something went wrong | what went wrong? |
| an error occurred | which error? what did it stop? |

## Soft words → plain names

| Soft | Plain |
|---|---|
| a small hiccup / a minor issue | what broke: "posting is broken" |
| not ideal / suboptimal | what's wrong with it: "it's slow: 40 s per video" |
| some challenges | the problem, named |
| didn't go as planned | what happened instead |
| unexpected behavior | what it did |
| may potentially | may, or will, or "I don't know" |

## Tech words and inside names → what they are

Say what the thing is or does. If the word must come back later, explain it once and then use it.

| Term | Plain version (adapt to the case) |
|---|---|
| deploy / ship | put the new version live (say where: "on the home server") |
| commit | save a checkpoint of the code |
| push | upload the code to GitHub |
| repo / repository | the project's code folder (on GitHub, or on this computer) |
| branch | a separate copy of the code to try changes on |
| PR / pull request | a request to add these changes to the main code |
| API | the way one program asks another for something |
| API key / token | a password a program uses |
| endpoint | the web address a program calls |
| cron / timer / scheduled job | a timer that runs X every day at 9:00 |
| env var / config | a setting saved on the machine |
| pipeline | the chain of steps (name the steps) |
| fallback | the backup |
| rate limit | the site only lets us ask N times a minute |
| quota / cap | the spending limit, with the number |
| feed / RSS | the address where a site publishes its news |
| database migration | a change to how the database stores things |
| bug | a mistake in the code |
| log | the record the program writes as it runs |
| UTC | the time in the reader's own time zone |
| tokens | money: "about $0.40" |
| "key #4", "slot 2", "P1", "SP0", "step-1 session" | what the thing is: "the main AI account", "the Monday posting time", "the urgent one", "the setup step", "the agent building the login page" |
